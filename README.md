## Features

- **Pure HTML, CSS, vanilla JS** -- no jQuery, no React, no build tools
- **Fully responsive** -- mobile-first design, works on all screen sizes
- **Single stylesheet** -- `style.css` with CSS custom properties for easy theming
- **Mobile navigation** -- hamburger menu with smooth slide-in drawer
- **Scroll reveal animations** -- IntersectionObserver-based fade-in effects
- **Menu category filtering** -- JavaScript-powered item filter with smooth transitions
- **Contact form** -- validation-ready with simulated submission feedback
- **Accessible** -- semantic HTML5, ARIA labels, keyboard-friendly navigation

## Getting Started

1. Open `index.html` in any modern browser
2. No server required -- everything works as static files
3. Replace SVG placeholders with real photography for production
4. Update contact details, menu items, and pricing as needed

## Customization

- **Colors**: Edit CSS variables in `:root` at the top of `style.css`
- **Fonts**: Swap the Google Fonts `<link>` tag in each HTML file
- **Content**: All text, prices, and descriptions are plain HTML -- edit directly
- **Images**: Replace files in `assets/img/` (SVG placeholders ship with the template)
